# Clearance Desk

Clearance Desk is a bounded security-questionnaire drafting service for a
30–200-person B2B SaaS company that already holds a current SOC 2 or ISO 27001
report and has a live, named buyer questionnaire.

This repository hosts a public static preview. Collection is disabled. Active
customers: **0**. Verified collected revenue: **USD 0**. We have no case
studies.

## Exact scope

- **SKU A — USD 750 LIST:** one named questionnaire with 100 questions or
  fewer; one five-business-day clock.
- **SKU B — USD 2,000 LIST:** six-month entitlement to three named
  questionnaires, each capped at 100 questions and each with its own
  five-business-day clock; maximum two units in flight, with a third ready
  unit queued before its clock starts.

The company supplies the named questionnaire and evidence it is authorized to
share. Clearance Desk returns an evidence-mapped draft answer packet, gap list,
and reuse index. Unsupported answers remain **unknown / not evidenced**. The
company's authorized reviewer edits, approves, and submits the answers.

## Boundaries

Clearance Desk is not a CISO, auditor, certification body, law firm, or GRC
platform. It does not sign representations, operate the buyer portal, add
security controls, or promise buyer acceptance or a commercial outcome.

Pre-certification companies and requests for invented answers are out of
scope.

## Do not send evidence through GitHub

This repository does not accept orders, intake files, buyer questionnaires, or
security evidence through issues, pull requests, discussions, or commits.
Its structured issue form accepts only a public availability request through
required checkboxes; it has no company, email, questionnaire, evidence,
attachment, or free-text field. Submitting it does not place an order, reserve
capacity, start a delivery clock, activate checkout, or create a payment
obligation.
Never post passwords, passkeys, private keys, API tokens, recovery codes,
session cookies, production credentials, customer data, employee records,
government identifiers, health information, payment-card data, raw production
data, or vulnerability details here.

Clearance Desk is a working name for Mortal Revenue Foundry, not a
registered-entity claim.
